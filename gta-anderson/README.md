# مَجلد: GTA Anderson

هذا المجلد يجمع موادًا لعرض وتشغيل شخصية ماركوس "أندرسون" في جلسات لعب الأدوار أو كمحتوى مهام داخل لعبة. الملفات الموجودة:

- Character.md — ملف الشخصية (السجل التفصيلي والمهارات والعتاد ونقاط اللعب).  
- intro.md — مشهد افتتاحي قصير لإدخال اللاعب في جو القصة.  
- scenarios.md — سيناريوهات لعب الأدوار والمهام المقترحة.

كيفية الاستخدام:
1. اقرأ `Character.md` لفهم دوافع الشخصية ومهاراتها الأساسية.  
2. ابدأ بمشهد `intro.md` لإعطاء السياق والهدف الأولي للاعب.  
3. اختر أحد السيناريوهات في `scenarios.md` لبدء مهمة مفصّلة.  
4. راوي اللعبة يمكنه تعديل النقاط والنتائج لتناسب مستوى اللاعبين.

نصائح إضافية:
- يمكن ترجمة الملفات أو توسيعها بإضافة مهام جانبية (side-quests) أو حوارات مفصّلة.
- إذا رغبت بترجمات إنجليزية أو ملفات منفصلة، أخبرني وسأنشئها.
